React Shop uses **Karla** for body copy and **Syne** for headings and buttons.
This pairing keeps dashboard data readable while giving page titles and calls to
action a distinct shop identity.

## Theme defaults

- Body font: `"Karla", "Helvetica Neue", Arial, sans-serif`
- Heading font: `"Syne", "Karla", sans-serif`
- Heading weights: 600-700 depending on level
- Button font: `"Syne", "Karla", sans-serif`, weight 650, no uppercase transform
- Heading letter spacing: h1 `-0.03em`, h2 `-0.02em`
